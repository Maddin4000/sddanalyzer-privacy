2. Datenverarbeitung in der App
Die App "SDD Analyzer" (Stopfanalyzer) speichert alle Daten ausschließlich lokal auf deinem Gerät. Es findet keine Übertragung deiner Daten an uns oder Dritte statt. Die App benötigt keine Internetverbindung und fordert keine entsprechende Berechtigung an.

Folgende Daten werden lokal in einer Datenbank auf deinem Smartphone gespeichert, wenn du sie selbst eingibst:

Tabakmarken, Einkaufsmengen und Preise
Stopf-Sitzungen (Datum, verwendete Maschine, Hülsentyp, Feuchtigkeit, Anzahl produzierter Zigaretten)
Angaben zu Zigarettenschachteln (Marke, Preis, Stückzahl)
Tägliche Rauchmengen, die du selbst protokollierst
Diese Daten dienen ausschließlich der Berechnung von Statistiken und Kostenübersichten innerhalb der App und verbleiben auf deinem Gerät.

3. Weitergabe von Daten
Es findet keine Weitergabe deiner Daten an Dritte statt. Die App enthält keine Analyse-, Tracking- oder Werbe-SDKs.

4. Backup
Die App nutzt die Standard-Backup-Funktion von Android (android:allowBackup="true"). Wenn du die automatische Gerätesicherung (z. B. Google-Konto-Backup) aktiviert hast, können deine App-Daten verschlüsselt in deinem Google-Konto gesichert werden. Dies unterliegt den Datenschutzbestimmungen von Google.

5. Deine Rechte
Da alle Daten ausschließlich lokal gespeichert werden, hast du jederzeit volle Kontrolle:

Löschen: Über die App-Einstellungen deines Geräts (Einstellungen → Apps → SDD Analyzer → Speicher → Daten löschen) oder durch Deinstallation der App werden alle gespeicherten Daten unwiderruflich gelöscht.
Es gibt keine Registrierung, kein Nutzerkonto und keine Möglichkeit für uns, auf deine Daten zuzugreifen.
